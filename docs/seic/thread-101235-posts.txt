"I know there are a number of high idle threads floating around, including one using a similar device from Intermotive, but I wanted to share my experience.  I wanted something simple, plug & play, without the need to run wires or install switches, etc.\n\nI have a 2023 with Sync 4, and went with the G-AFIS506VSX-BP from Intermotive, which includes the correct t-harness for connecting the unit to the OEM Gateway module.\n\nInstallation was very straightforward, if you're concerned:\n\n1. Disconnect the battery.\n2. Drop the glovebox.\n3. Disconnect the gateway module (instructions say to remove the module, but I was able to access the plug without doing so).\n4. Connect the T-harness between the OEM harness and the gateway module.\n5. Connect the 4-pin lead to the device (you may want to leave it hanging out while you configure).\n6. Connect the additional harness included to enable VBAT trigger.\n6. Once everything is configured, do some cable management, secure the excess harness and device somewhere safe within the dash.\n7. Push the glovebox back into position, and you're done!\n\nBy default, the device will set your idle to 1500rpm any time the VBAT signal is below 12.5V.  This may be enough for some, but I wanted to be able to engage it as desired to keep things topped off, so I opted to enable the Parking Brake trigger to force it into high idle when I need to charge stationary.  Any time I'm parked and idling, simply engaging the parking brake will engage the high idle.\n\nThe device also has 3 speeds that can be triggered by grounding one of three included wires on the second harness.  As some have done prior, this can be accomplished with a switch, but I haven't opted to use this method, as the parking brake trigger suits my requirements.  The speeds are adjustable, but any automatic trigger(VBAT, Parking Brake) will engage speed 1 (by default, 1500rpm, adjustable).\n\nI had planned to install a switch for speed selection, but I think I prefer the parking brake solution and it requires absolutely no additional wiring or switches.  All you need to do is run through a set of operations to engage the parking brake trigger, cycle the key, and it works.\n\nAnyway, if you are trying to save some cash, this can be accomplished using the other methods highlighted on the forums, but I really didn't want to dig into the harness and run all the wiring through the firewall, etc., so the simplicity of this option called to me.\n\n========POST BREAK========\n\nI know there are a number of high idle threads floating around, including one using a similar device from Intermotive, but I wanted to share my experience.
